# exegacha-assets

Public static assets for **EXE GACHA** — a Y2K collectible blind-box widget for Twitch/YouTube streamers, part of the **form&soul.exe** shop.

Served via GitHub Pages. Base URL: `https://feder0707.github.io/exegacha-assets/`

## Contents

- `capsule_sprite_sheet.png` — 6×6 sprite sheet (36 frames) for the gachapon capsule animation
- `capsule_static.png` — single-frame capsule reference
- `items/01_floppy.png` … `items/30_virtual_pet.png` — the 30 collectible item sprites
